# 制造业企业AI化转型

面向制造业企业负责人与AI应用工程师的业务问题自查、案例研究和开源项目选型参考。原生HTML / CSS / JavaScript，网站运行无第三方前端依赖、无后端、无外部CDN。

## 项目定位

制造业企业推进AI应用时，常见的困难是难以把经营问题转化为明确的实施任务：问题发生在哪个环节、现有系统缺少什么、需要准备哪些数据、哪些动作适合AI辅助，以及如何判断试点是否有效。

本项目围绕这些问题组织内容，将业务问题识别、公开案例研究放在同一条阅读路径中。企业负责人可以据此形成试点讨论清单。

**推荐路径：选择岗位 → 补充业务条件 → 查看问题与方案 → 对照公开案例 → 评估开源项目 → 明确试点范围与验收方式。**

## 适合谁使用

| 使用者 | 可以重点了解的内容 |
| --- | --- |
| 制造业企业负责人、厂长 | 识别交付、质量、库存和经营管理中的典型问题，了解试点产物与所需配合 |
| 计划、采购、仓储、质量、设备等业务人员 | 对照岗位现状，梳理人工流程、数据缺口、异常处理和人员职责 |
| 企业IT与数字化负责人 | 判断如何复用现有ERP、MES、WMS、QMS及业务数据，明确接口与权限边界 |
| AI应用工程师、实施与技术服务团队 | 查看具体实施步骤、数据准备要求和开源项目候选，减少重复开发 |
| AI学习者与交流活动参与者 | 通过业务案例和模拟样例理解企业AI应用的基本方法 |

## 板块一：问题自检与案例查看

### 1. 基于业务条件的初步自查

从12类岗位进入，选择优先核查的问题，补充生产组织方式、问题发生频率和数据基础。系统使用本地规则生成初步建议，展示：

- 所选条件对应的核查依据；
- 建议先验证的业务产物；
- 需要参与的岗位与人员责任；
- 数据准备、实施范围与适用边界。

例如，资料主要分散在纸张、群聊和个人经验中时，建议先整理授权样本并采用辅助处理；已有业务系统记录时，可从只读接入和结果核验开始。选择不同数据条件，会得到不同的实施准备建议。

### 2. 25类业务问题与实施方案

每个问题详情按业务现状、问题诊断和AI落地方案组织，说明当前流程、系统缺口、可能影响、具体处理步骤、交付结果及验收思路。业务摘要与咨询入口前置，完整来源与工程说明保留在页面中。

| 方向 | 覆盖的问题 |
| --- | --- |
| 生产与供应链 | 排产与交期、齐套欠料与催交、库存账实与呆滞、采购比价与发票应付 |
| 质量与追溯 | 来料判退与供应商质量、过程质检与漏检、客诉与8D、批次追溯与出货合规 |
| 设备与知识 | 设备点检与异常升级、预测性维护与备件、老师傅经验传承、图纸与工艺版本 |
| 经营与数据 | 非标报价、财务对账与订单成本、订单全链路透明、报表自动化、数据口径与跨系统对账、主数据治理 |
| 渠道与外贸 | 外贸单证审单、跨境装车与运费、经销动销、电商补货与广告联动、门店结算对账 |
| 组织与资产 | 一线采用与AI抵触、能耗与资产盘点 |

### 3. 公开参考案例与场景样板

收录49条公开参考案例和6条操作级场景样板。案例详情分为“问题、做法、落地步骤、结果”，保留来源链接、发布方、证据等级以及未披露信息，帮助使用者区分可参考的经验和仍需自行验证的条件。

案例摘要便于先判断业务相关性，再查看完整依据。读者可以选择本企业对应的问题，进入更具体的业务方案，而不必将大型企业的平台实践直接套用到自己的工厂。

## 典型使用方式

**企业负责人：**先选择岗位与业务条件，找到与自身现状相符的问题；重点查看建议产物、人员配合和试点边界，再准备一次真实任务的授权样本进行讨论。

**业务与IT共同评估：**围绕同一个问题，对照现有流程和系统数据，确认缺字段、版本、接口和权限等条件，约定先验证哪一段流程。

**AI应用工程师：**查看25类问题的具体落地方案与示例，了解数据准备、程序校验、AI职责、人工确认和验收要求。

## 技术特点

- 原生HTML、CSS与JavaScript，无前端框架和构建步骤。
- 网站运行不依赖数据库、后端服务、外部CDN或在线模型。
- 内容随项目文件一起提供，可在本地离线浏览；访问第三方来源和GitHub链接需要网络。
- 自查、示例和咨询文本准备在浏览器本地完成，不自动上传或发送。
- 支持手机与桌面阅读，并提供DOM渲染与交互测试。

## 使用

直接打开 `index.html`，或使用本地预览：

```bash
npm run serve
```

访问 http://127.0.0.1:8130/ 。默认仅本机可访问。

测试需要Node.js 20.19+（或22.12+）与开发依赖：

```bash
npm ci --no-audit --no-fund
npm test
```

当前包含145项DOM渲染与交互断言。测试不证明外部项目可部署、AI效果或客户转化率。

## 内容边界

这是静态演示与研究参考，不连接企业ERP/MES，不调用在线大模型，不发送群消息。交互样例使用明确标注的模拟数据和本地规则。自查建议不是正式诊断，不能直接决定质量放行、付款或生产控制。

案例为公开资料整理，不代表维护者的客户或交付业绩。A/B等证据等级描述来源性质，不是效果评分，也不代表独立审计。部分问题流程与影响为分析推断，并已标注。案例来源集中、缺失信息及许可证风险说明均保留。

咨询弹窗只在本地准备沟通文本，不会自动发送；页面保留项目维护者业务联系方式。复用部署时请自行替换咨询信息。
